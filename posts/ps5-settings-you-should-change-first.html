PS5 settings to change first after a fresh setup

Most PS5 settings tutorials tell you to change everything. Most of them change nothing. These are the ones that actually affect your experience.

Published 8 January 2026 · Updated 8 January 2026 · 7 min read · by PC Games vs PlayStation

Settings menus are where a lot of gaming advice goes wrong, because changing something always feels like progress. It is not. On a console the developers have already tuned for the hardware, so many settings make the picture worse and none of them make it faster.

What follows is the short list that is worth your time, in the order we would do it. Menu paths are given from the PS5 home screen.

1. Solve storage first, because it is the one you will notice

The built-in drive fills up quickly. Modern games are large, and a full console will quietly start refusing to install or update things, which is far more annoying than it sounds.

Go to Settings → System → Storage. There are two things worth doing:

  • Move games you are not currently playing to an external USB drive. You can do this from the game's tile options or from the storage screen. You will need to plug the drive in and press a button to start playing again, which is a real trade-off, but it frees the internal drive cheaply.
  • Buy the official PlayStation Plus M.2 SSD expansion if you would rather not deal with that. It is supported by the console, it is faster than most external drives, and games moved to it load as though they were internal. It is one of the few accessories we recommend without qualification.

Also delete what you have finished. The storage screen sorts by size, which makes this a two-minute job that most people never do.

2. Turn on 120 Hz if your television supports it

This is the single biggest visual upgrade available on a PS5, and plenty of people never switch it on.

Go to Settings → Screen and Video → Video Output → Video Output Information. If your television and its cable can do 120 Hz, the option appears here. If it does not appear, the television, the port or the cable is the limiting factor, and no console setting will change that.

You will also want to enable VRR in the same area if your television supports it. Variable refresh rate smooths out the small frame-rate wobbles that otherwise show as subtle judder in scrolling and panning.

Before you finish, check Settings → Screen and Video → Screen and make sure the resolution is set to Automatic or to the highest your set accepts. Some televisions end up forcing a lower mode after an update.

3. Calibrate HDR properly

The PS5 will happily output HDR, and plenty of televisions will happily accept it, and the result can still look flat or washed out because the set is out of calibration.

Play a game with a bright, dark scene and open the PS5's Adjust Picture option. Set brightness to roughly 50 for a typical living room, then use the in-game calibration grey bars to set contrast so the darker bars are dark without the bright bars clipping. After that, the only change worth making is raising or lowering the whole image with brightness, which does not crush detail the way a contrast change does.

This takes ten minutes and is the difference between HDR looking like a gimmick and looking correct.

4. Understand rest mode, and why you should not fully power down

Settings → System → Power lets you choose between Rest Mode and Power Off. People often switch this off thinking it saves energy.

In Rest Mode the console downloads and installs updates in the background and applies them while you are asleep in the sofa. In Power Off it may still download, but install happens when you next start the console, which means a game you launch immediately may need updating first. For most people, Rest Mode is the better default despite using a little more power.

5. Set the right display mode per game

Under Settings → Screen and Video, each installed game has its own display mode option. This is a per-game setting, and it matters more than the global one.

If a game supports 120 Hz and your television does, that game gets its own 120 Hz mode. Games without that support need no change. But it is worth checking, because the console will happily leave a capable game running in a 60 Hz mode and the difference is significant in anything that moves.

6. Tune the controller to your hands

Settings → Accessories → Controller → Controller Profile holds several options that make a real difference:

  • Haptic feedback strength. Turn it down if it makes your hands tired, up if you rely on it for timing. This is a genuine preference, not a right or wrong answer.
  • Trigger resistance. The analogue triggers can be adjusted, or individual games can lock them to digital for a snappier feel. Worth an afternoon of experimenting.
  • Button assignment. Swapping the face buttons to match a different layout is one of the best accessibility features on the console, and almost nobody uses it.

7. Accessibility settings worth knowing about

Under Settings → Accessibility there is a large set of options that include magnifier, text size, screen reader, colour filters, and a wide range of remapping options. A few are genuinely useful for everyone:

  • Magnifier and auto magnify make small text readable without a second screen.
  • Large text applies across the system interface, which matters on a large television across a room.
  • Colour filters help with colour vision differences and with badly calibrated panels.
  • Audio output options can change how surround and dialogue are mixed, which rescues some games on some setups.

8. Sort out your captures before you need them

Under Settings → Captures → Capture Settings you can decide what gets recorded automatically. This matters because capturing a good moment in a console game is not always simple, and you can lose a clip to a menu you did not know existed.

Set a sensible auto-capture length, confirm your screenshots are saved, and check that your storage is not full, because the console will stop saving captures when it runs out of space and will not tell you loudly.

What you can safely ignore

Some advice out there is filler. For the record, here is what we would leave alone:

  • Disabling rest mode updates. You will only make yourself wait longer for games.
  • Turning off background downloads entirely. Fine if you prefer to manage downloads yourself. It does not make the console faster.
  • Editing system file caches. There is nothing there that improves performance.
  • Overclocking a console. The PS5 does not expose this, and the fan noise means you would not want it to.

If you only do three things

Free up storage. It is the setting you will notice most in daily use. Enable 120 Hz and VRR if your set supports them. Calibrate HDR. Those three will improve your experience more than everything else on this list combined.

Firmware updates can move menu locations, so if a path here does not match your console, check for the latest system software first.

Comparing to PC? Some of these settings simply do not exist on PC, which is exactly the argument in why PC ports can look better than the console version.
